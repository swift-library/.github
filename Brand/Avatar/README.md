# Organization avatar sources

[DESIGN.md](../../DESIGN.md#iconography) owns the background, layer order,
and material settings. `Bird.svg` and `Dots.svg` are flat source layers for
Icon Composer; native effects and masks are applied during generation.

The Swift bird is supplied brand artwork from
[Swift.org](https://www.swift.org/assets/images/swift.svg), positioned on a
transparent canvas. Swift and the Swift logo are trademarks of Apple Inc.
The dot field, native material treatment, and organization palette belong
to this avatar composition. This artwork is not used as a package glyph or
as a generic icon skill example.

Generate the `swift-library` app entry with `apple-app-icon-design`, review
all native appearances and the web set, and verify drift before replacing
delivered assets. Repository README and documentation logos use the separate
framework-style entry in the same design document.
