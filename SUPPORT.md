# Support

Start with the affected repository's README and documentation. Include the
package version or commit, Swift and Xcode versions, operating system, and a
small example when asking for help.

Open an issue in that repository for usage questions, reproducible bugs or
feature requests. For shared policy or reusable workflow questions, use the
[shared standards issue tracker](https://github.com/swift-library/.github/issues).

Report vulnerabilities privately through the affected repository's Security
tab, using **Report a vulnerability**. Report community conduct concerns to
[swift-library-conduct@gmail.com](mailto:swift-library-conduct@gmail.com).
